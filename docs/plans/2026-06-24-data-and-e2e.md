# 数据与端到端验证计划

> 合并自 06-24 三个子计划：AI 引擎 LLM 集成、数据采集增强、真实策略 e2e 验证

---

## A. DeepSeek LLM 集成到 Report Analysis

**Goal:** 将 `report_analysis` 模块从纯规则引擎升级为 LLM 驱动，接入 DeepSeek API。

**Architecture:** 新增 `llm_client.py` 封装 DeepSeek 调用，`ReportAnalyzer` 新增 LLM 模式（优先 LLM，失败 fallback 规则引擎）。密钥统一管理：根目录 `.env`（gitignored）+ `.env.example`，Python 包纯读 `os.environ`，不引入 dotenv。

**Tech Stack:** Python httpx, DeepSeek OpenAI-compatible API, pytest

**Task:** 实现 llm_client.py → ReportAnalyzer LLM 模式 → fallback 逻辑 → 测试

---

## B. 数据采集增强

**Goal:** 新增 mootdx + 腾讯适配器，补充财务/估值数据，解决 data/ gitignore 问题。

**Architecture:** 新增两个数据源适配器，扩展 seed-data 脚本，调整 gitignore。不改动 data-center 存储层，不改动上层业务。

**Tech Stack:** Python (mootdx), TypeScript (data-collector adapters)

### 适配器

| 适配器 | 数据源 | 协议 | 数据类型 |
|--------|--------|------|----------|
| MootdxAdapter | 通达信行情 | TCP 7709 | bar, instrument |
| TencentAdapter | 腾讯财经 | HTTP | valuation (PE/PB/市值) |

### Task 清单

- **Task 1: MootdxAdapter** — Create `services/data-collector/src/adapters/mootdx-adapter.ts`，Modify types/index/bootstrap/source-selector。Python 子进程调用 mootdx，TCP 连通达信，`Quotes.factory()` → `client.bars()`。bar 优先级 mootdx 排第一。
- **Task 2: TencentAdapter** — Create `tencent-adapter.ts`，Modify types/index/bootstrap。HTTP GET `qt.gtimg.cn`，GBK 编码，`~` 分隔，字段 39=PE/46=PB/44=总市值。
- **Task 3: 扩展 seed-data** — Modify `scripts/seed-data.ts`，追加复权因子/财务报告/估值数据采集。
- **Task 4: gitignore 修复** — `data/*.db` 替代 `data/`，创建 `data/.gitkeep`。

**实现顺序：** Task 4 → Task 1 → Task 2 → Task 3

**边界约束：** data-collector 不存储数据/不提供查询/不感知上层业务。不新增 Repository。不改动 data-center Provider 层。

## C. 真实策略端到端验证 (v2)

**Goal:** 用真实 A 股数据跑通 5 个策略的完整回测→报告→前端展示链路。

**Architecture:** 四阶段：(0) 修复已知问题; (1) 数据检查; (2) Python 直接回测; (3) Worker+API 全链路; (4) 前端展示。

**Tech Stack:** Python (baostock), TypeScript (vitest, Node.js)

### 关键事实

- API 端口 **3002**，入口 `apps/api/src/index.ts`
- Worker 独立进程，轮询 `http://127.0.0.1:3002`
- 前端 vite proxy → `http://localhost:3002`
- PythonBridge 用 `findProjectRoot()` 定位 `data/quant.db`

### Task 清单

- **Task 0.1:** 修复 report-mapper 丢失 drawdownCurve/monthlyReturns/annualReturns
- **Task 0.2:** gitignore 修复（同 B-Task 4）
- **Phase 1:** 数据检查（验证 quant.db，不足则 seed-data）
- **Phase 2:** Python 直接回测（dual_ma/rsi/bollinger_band/macd/kdj，验证 totalTrades > 0）
- **Phase 3:** Worker+API 全链路（e2e 测试 + 手动验证）
- **Phase 4:** 前端构建验证（build + dev + 浏览器）

**注意事项：** mootdx 走 TCP 需国内网络；腾讯估值是实时快照非历史序列。
