## 四、绩效指标

### 4.1 收益类

| 指标 | 说明 |
|------|------|
| 累计收益率 | 策略 vs 基准 |
| 年化收益率 | 长期盈利能力 |
| 超额年化收益 | 策略 - 基准 |

### 4.2 风险调整收益

| 指标 | 公式 | 参考标准 |
|------|------|----------|
| 夏普比率 | (年化收益 - 无风险利率) / 年化波动 | > 1 可接受，> 2 优秀 |
| 索提诺比率 | 用下行偏差替代标准差 | 比夏普更严格 |
| 卡玛比率 | 年化收益 / 最大回撤 | 衡量回撤性价比 |
| 信息比率 | 超额收益均值 / 跟踪误差 | > 0.5 可接受 |

### 4.3 回撤类

| 指标 | 说明 |
|------|------|
| 最大回撤 | 峰值到谷底最大跌幅 |
| 最大回撤持续时间 | 从峰值到新高的恢复周期 |
| 回撤超过 10%/20% 的次数 | — |

## 八、稳健性检验

| 检验项目 | 方法 | 判断标准 |
|----------|------|----------|
| 参数敏感性 | 参数 ±20%，观察绩效变化 | 绩效稳定（非剧变） |
| 样本外测试 | 前 70% 训练 / 后 30% 验证 | 衰减 < 20% |
| 子区间分析 | 按年/市场状态拆分 | 各区间均跑赢基准 |
| 幸存者偏差 | 包含已退市股票 | 影响程度 |
| 前视偏差 | 检查是否使用未来数据 | 无 |

## 九、结论与建议

结构化输出：

```
优势：策略在哪些市场环境下表现突出
风险：策略可能失效的场景
改进：基于回测发现的优化方向
实盘建议：建议资金规模、初始仓位、必须风控规则
```

---

## 附：关键红线

- 最大回撤 > 30%（择时策略应 < 20%）
- 样本外绩效衰减 > 50%
- 参数敏感性极高
- 交易成本吃掉大部分收益
- 回测区间 < 3 年

## 附：关键公式

```
年化收益 = (1 + 累计收益)^(252/交易日数) - 1
夏普比率 = (R_p - R_f) / σ_p
最大回撤 = max[(峰值 - 谷值) / 峰值]
信息比率 = E[R_p - R_b] / σ(R_p - R_b)
卡玛比率 = 年化收益 / |最大回撤|
```
